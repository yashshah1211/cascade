## Evidence presentation rules

**Original UI screenshot:** Captured from an authenticated historical post element. This is genuine browser imagery.

**Authenticated API presentation card:** Values come from the real post and authenticated author via read-only GET requests, rendered large for legibility. Explicitly labeled a presentation card, not a screenshot.

**Artifact readout:** Values come from original locally generated JSON/Markdown, checked structurally and hashed. Claims are limited to actual local file creation.

**ACP tool result:** Displayed only when the exact model-generated call and tool-owned structured result pass strict verification. Otherwise omit this scene, and never fabricate a transcript.
